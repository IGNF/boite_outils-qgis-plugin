
# IGN_boite_outils

This plugin brings together various semantic and topological processing functions.

## Pré-requis

Mandatory : The "plugin\_maitre" must be installed.
Link to the plugin maître : [maitre-qgis-plugin sur GitHub](https://github.com/IGNF/maitre-qgis-plugin)

## Fonctionnalités

French : 
* Déplacement d'un point commun à plusieurs tronçons. 
* Copie d'attributs entre entités
* Recherche d'entités par cleabs ou par identifiant




English :
* Moving a point shared by multiple segments.
* Copy of attributes between entities
* Search for entities by CLEABS or by identifier.
